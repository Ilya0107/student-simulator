## Расчёт оценки

Порог зависит от здоровья:

- **Здоровье < 30**: знания ≥ 90 → `4`; ≥ 80 → `3`; иначе `2`.
- **Здоровье ≥ 30**: знания ≥ 85 → `5`; ≥ 75 → `4`; ≥ 65 → `3`; иначе `2`.

Автомат `3` — если `здоровье ≤ 20` и `знания ≥ 90` (учёба ценой здоровья).

## Подкуп

| Исходная оценка | Цена | Исходы (по броску 1–100) |
|:---------------:|:----:|--------------------------|
| 2 | 700 ₽ | ≤40 → 3, ≤50 → 4, ≤80 → без изменений, иначе скандал (отчисление) |
| 3 | 500 ₽ | ≤50 → 4, ≤60 → 5, ≤80 → 2, иначе без изменений |
| 4 | 500 ₽ | ≤40 → без изменений, ≤70 → 5, ≤90 → 3, иначе 2 |

## Секретная концовка

Оценка выставляется, и если одновременно `знания ≥ 90`, `здоровье ≥ 40`,
`деньги ≥ 400` — открывается секретная концовка.
